# TengaAgent Pilot Support Template

- Tenant/business:
- Channel: web / WhatsApp / voice note
- Approximate time:
- Conversation ID:
- Provider message ID (WhatsApp only):
- Request ID (if available):
- Observed behavior:
- Expected behavior:
- Billing/readiness error code (if any):
- Human handoff state:
- Resolved: yes / no
- Resolution notes:

Do not paste credentials, access tokens, authorization headers, JWTs, webhook secrets, API keys, payment-card data or OTPs into incident notes.
