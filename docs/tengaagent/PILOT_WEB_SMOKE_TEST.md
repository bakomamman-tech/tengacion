# TengaAgent Web Pilot Smoke Test

1. Open the published tenant agent route.
2. Start a new session and ask a grounded business question.
3. Confirm the first session consumes one monthly conversation allowance.
4. Send additional messages in the same session and confirm conversation count does not increment again.
5. Confirm lead capture / appointment actions only appear when enabled.
6. Claim human handoff and verify AI suppression.
7. Confirm a different tenant/session cannot retrieve the transcript.
