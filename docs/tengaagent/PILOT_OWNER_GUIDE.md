# TengaAgent Pilot Owner Guide

During a controlled pilot, the owner should use the TengaAgent owner workspace to:

- review the Plan & Usage panel;
- review Pilot Readiness before enabling a channel;
- publish or pause the business agent;
- maintain business knowledge;
- review captured leads and appointments;
- claim human handoffs when AI should stop responding;
- monitor follow-ups and outcomes.

If Pilot Readiness shows a channel as blocked, do not bypass the server gate. Resolve the missing subscription, provider configuration or tenant connection instead.
